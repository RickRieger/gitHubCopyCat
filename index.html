About this project

DemoEats isn't a real company. This page is a front-end layout exercise I built at the Code Immersives bootcamp in February 2021, modeled on the structure of a food-delivery homepage: a split hero section, a three-column feature row, an image-and-text section and a multi-column footer, all with HTML and CSS Flexbox. The search box and links are placeholders.
